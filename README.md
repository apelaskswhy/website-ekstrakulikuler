# website-ekstrakulikuler
Proyek Website Ekstrakulikuler SMK Kartika XX-1 Makassar

**Konsep**
Yang mengikuti proyek: Adit, Arzha, Farhan, Awal, dan Mughni

1. Eks/Intrakulikuler = ROHIS, OSIS, MPK, Paskibra, Pramuka, Karate, Panduan Suara, TechnoPious
2. Gambar, jam latihan, lokasi, dan info tentang ekstrakulikuler di Website
3. List jumlah anggota ekskul (opsional)
4. Kegiatan yang dilakukan (list)
5. Pembina ekskul jadi admin
6. Deskripsi dari setiap ekskul
7. Laporan tentang aplikasi
8. Aplikasinya bisa berjalan di PC dan HP (multiplatform)
9. Penyimpanan foto di Google Drive
10. Pengambilan foto oleh guru-guru
11. Pembuatan proposal serta anggaran jasa (500/1000)
12. APK memiliki tabel untuk kehadiran siswa
13. Absensi kehadiran dapat dilakukan dengan ceklist oleh Admin
14. Menggunakan aplikasi timestamp WAJIB
15. Bisa mengunggah di APK secara langsung
16. Ada tutorial cara menggunakan timestamp (pop up)
17. Foto yang diunggah di dokumentasi hanya foto yang bagus dan rapi
18. Data dapat dilihat oleh Pak Hendra

Durasi proyek 1 minggu, maksimal 3 minggu
